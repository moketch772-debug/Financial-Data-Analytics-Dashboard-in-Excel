# Financial-Data-Analytics-Dashboard-in-Excel
Sales, COGs and Profit Insights by Product, Segment and Country.
This Excel dashboard provides a consolidated view of sales, COGS, and profitability performance across products, segments, countries, and time. It highlights key KPIs (Total sales, COGS, profit, units sold, and margin), compares profitability by product and country, tracks sales trends over time, and analyzes COGS, discounts, and margins to support data-driven commercial and financial decisions.
